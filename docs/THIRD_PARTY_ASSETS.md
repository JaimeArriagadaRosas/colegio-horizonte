## Asset policy

1. Do not use emoji as interface or README iconography.
2. Prefer Lucide for generic interface icons.
3. Prefer project-owned SVG diagrams for repository documentation.
4. When a third-party asset is added, record its canonical source, license, local path and any modifications in this file.
5. Do not download assets merely for decoration. Every external asset must have a concrete informational or interface purpose.
6. Do not assume an open asset license grants trademark rights over a represented brand.
